Je potřeba dokončit Supabase nastavení. Zkontrolujte údaje v supabase-config.js a spusťte SQL ze souboru supabase/schema.sql v Supabase SQL Editoru.
Editor bez ochrany zápisu. Každý návštěvník může nabídku změnit přes Supabase; skrytá adresa editoru není zabezpečení.
Úpravy se po uložení projeví na veřejné stránce.

  1. V Supabase SQL Editoru spusťte SQL ze souboru supabase/schema.sql.
  2. V souboru supabase-config.js nastavte Project URL a veřejný publishable key svého projektu.
  3. Toto nastavení dovoluje veřejné úpravy bez přihlášení; skrytá adresa editoru je pouze pohodlí, ne ochrana.
